工欲善其事，必先利其器。下面是我目前每天都在用的开发配置。

## 终端

我用的是 **zsh** 加上几个提升效率的小工具：

```bash
# 更好用的 ls 和 cat
brew install eza bat

# 模糊搜索，配合 Ctrl+R 查历史命令
brew install fzf
```

在 `~/.zshrc` 里加几个别名：

```bash
alias ls="eza --icons"
alias cat="bat"
```

## 编辑器

主力是 **VS Code**，必装插件：

- GitLens：看每一行代码是谁、什么时候改的
- Error Lens：把报错直接显示在代码行尾
- Prettier：保存时自动格式化

## AI 助手

现在写代码基本离不开 AI 了。我的用法是：

- **解释陌生代码**：读别人的项目时先让 AI 讲一遍结构
- **写测试**：把函数贴给它，让它补边界情况
- **不直接复制**：生成的代码一定自己读懂再用

## 小结

工具只是手段，最重要的还是**持续折腾、持续记录**。你有什么私藏工具？欢迎告诉我。
